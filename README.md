# Professional Console Speed Test

Продвинутый консольный скрипт на Python для точного замера скорости скачивания данных по URL. Реализован с учетом сетевых особенностей (TCP Slow Start, кэширование CDN) и изолирует задержки сервера от реальной пропускной способности канала.

## Ключевые особенности
- **TCP Warm-up (Прогрев соединения):** Выполняется предварительный запрос для «разогона» TCP-окна, чтобы первый замер не был искажен сетевым стеком.
- **Cache-busting:** Динамическое добавление уникального метчика времени к каждому запросу исключает отдачу файлов из кэша CDN-узлов.
- **Изоляция TTFB:** Время отклика сервера (латентность) не учитывается при расчете скорости — замеряется исключительно чистое время скачивания полезной нагрузки.
- **Потоковое чтение (Chunked):** Файлы скачиваются чанками по 64 КБ, что предотвращает скачки потребления оперативной памяти.
- **Keep-Alive:** Использование `requests.Session()` минимизирует накладные расходы на повторное открытие TLS/TCP-соединений.

## Требования
- Python 3.8+
- Библиотека `requests`

## Единицы измерения скорости
В итоговом отчете скорость скачивания выводится в двух форматах:
- **Мбит/с (Mbps)** — Мегабиты в секунду (основная сетевая метрика пропускной способности).
- **МБ/с (MB/s)** — Мегабайты в секунду (реальная скорость скачивания файлов).

## Установка и Использование

1. Установите зависимость:
   ```bash
   pip install requests
   ```

2. **Способ А (Через конфигурационный файл):**
   Укажите нужный URL в файле [config.py](<config.py>), а затем запустите скрипт без аргументов:
   ```bash
   python3 speedtest_pro.py
   ```

3. **Способ Б (Через аргументы командной строки):**
   Передайте URL и нужное количество запросов (`-n`) напрямую:
   ```bash
   python3 speedtest_pro.py https://mirror.yandex.ru/centos/7.9.2009/isos/x86_64/CentOS-7-x86_64-Minimal-2009.iso -n 5
   ```
